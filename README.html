Storage migration

Небольшой проект для инвентаризации, сверки и скачивания изображений. Есть проверка доступа к R2. Загрузка в R2 и восстановление баз пока не реализованы.

Установка

Нужны Python 3.14 и make. В терминале папки проекта:

make setup
make deps
make check

Окружение создаётся в .venv внутри проекта. Зависимости boto3 и Pillow устанавливаются туда же. Системный Python не изменяется; setup не скачивает Python. В PyCharm выберите существующий интерпретатор .venv/bin/python.

Команды

КомандаДействие
make configureСохранить endpoint, имя бакета и ключи локально; скрытый ввод.
make check-r2Проверить доступ к бакету без списка и передачи объектов.
make inventoryИнвентаризация метаданных локальных папок.
make reconcileСопоставление ID манифеста с локальными файлами.
make downloadСкачать до 20 недостающих фото с живым прогрессом.
make download LIMIT=100Скачать до 100 недостающих фото.

Локальные настройки

.local/credentials.json хранит настройки R2, .local/sources.json — папки инвентаризации, .local/dataset.json — путь к CSV, папке изображений и разрешённые хосты источника. Примеры формата — в README.md. Существующие ключи не перезаписываются. Они защищены правами доступа к файлу, но не зашифрованы.

Скачивание

Команду запускает пользователь. Она обращается к источнику по HTTPS, сохраняет исходные байты и не вызывает R2. Прежние файлы и разметка не изменяются. Новые изображения декодируются и проверяются чтением обратно перед публикацией файла. Повторный запуск пропускает существующие файлы; их наличие само по себе не доказывает целостность. Имя файла имеет вид image_id.jpg независимо от исходного формата.

Прогресс обновляется каждую секунду. Процент относится к обработанным файлам текущей партии, включая ошибки; МБ — к успешно сохранённым файлам. Пределы: 4 потока, тайм-аут сокета 30 секунд, 25 МиБ на файл, до 204 файлов за запуск.

Что входит в Git

Только общая документация, Makefile, описание Python-проекта и исходники scripts/*.py. Остальные пути по умолчанию игнорируются: данные, окружение, ключи, локальные настройки, внутренние инструкции, журналы и отчёты. Перед публикацией проверяйте подготовленный список и содержимое файлов.

Результаты и ограничения

HTML-отчёты и журналы остаются в reports. Проверка доступа к R2 не доказывает право записи или наличие проверенных копий. Команды не удаляют исходные данные. Проверка окончательного восстановления из R2 ещё не реализована.
